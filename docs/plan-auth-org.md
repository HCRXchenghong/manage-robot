# 身份与组织体系（等保三级）实施记录 · v1

> 平台更名：机器人集中管理调度平台。本轮交付：登录（账密+人机验证）、
> 三级权限（超管/普通管理员/用户）、分组（独立项目平台）、防搜索引擎。

## 1. 登录与会话

- 流程：账号密码 → 图形验证码（服务端渲染 PNG，5 分钟有效、错 3 次作废）→ 会话 Cookie（HttpOnly、SameSite=Lax）。
- 等保策略：密码 ≥8 位且含 大写/小写/数字/符号 中 3 类；连续失败 5 次锁定 30 分钟；
  会话闲置 30 分钟 / 绝对 8 小时失效；改密后其余会话全部失效；密码 180 天到期提醒；
  登录成功/失败/锁定/登出/改密全部进审计（内存环 + PG audit_log）。
- 全站鉴权中间件：未登录访问 /api/*、/open/*、/ws/* 一律 401；
  仅 /api/maps/upload 放行本机车端上报（loopback），车云数据链路不受登录影响。

## 2. 三级权限与分组

| 角色 | 上限 | 能力 |
|---|---|---|
| super 超级管理员 | 全局 ≤10 | 所有分组可见可调度；管理所有人与分组；调配额 |
| group_admin 普通管理员 | 每分组配额（默认 5） | 仅本分组可见可调度；管理本分组内成员（建号/改组/重置密码/删号） |
| user 用户 | 每分组配额（默认 10） | 仅本分组可见可调度；无管理面 |

- 分组 = 独立项目平台：车辆经网关注册带 group（gateway --group / RA_GROUP），
  地图/任务/事件随车辆分组过滤（服务端快照过滤 + 前端双保险）。
- 配额默认 5 管理员 / 10 用户每分组，超管可在「组织管理」页调整；超管总数硬限 10。
- 越权实测：普通管理员建超管/跨分组建号/建分组/重置超管密码 均被拒；本分组建号放行。

## 3. 防搜索引擎

- /robots.txt：User-agent: * Disallow: /
- 响应头：X-Robots-Tag: noindex, nofollow, noarchive（全站）
- index.html：meta robots noindex + 空 description；标题为平台名。
- 配套安全头：X-Content-Type-Options / X-Frame-Options / Referrer-Policy / Cache-Control: no-store。
