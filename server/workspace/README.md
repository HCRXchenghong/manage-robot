# workspace：远程工作空间与诊断会话域

工作空间域为已授权的运维人员提供终端、图形会话和车辆诊断通道。它与远程
驾驶控制域完全隔离：工作空间权限不能产生 `ControlCommand`，终端会话也不能
绕过 Gateway 或 Safety Arbiter。

## 会话边界

1. Fleet-hub 根据人员、分组、车辆生命周期和审批策略创建短期会话授权。
2. Workspace Broker 只把已授权会话路由到对应车辆的 `workspace-agent`；浏览器
   不直接连接车辆监听端口。
3. 车端 Agent 通过 Gateway 建立反向加密通道，并对每个会话执行令牌、空闲超时、
   并发数和资源上限检查。
4. 命令输入、诊断请求、审批人、结果、断开原因和会话恢复均写入不可变审计记录。
5. GUI/RViz 流使用独立媒体会话和访问令牌，不能复用终端令牌或控制租约。

## 协议与安全要求

- 控制台使用 HTTPS/WSS；车辆侧使用设备身份认证的反向通道。
- 高危命令按命令目录执行审批和双人复核；字符串黑名单不作为唯一安全措施。
- 会话必须绑定 `user_id`、`vehicle_id`、`group_id`、`approval_id` 和过期时间。
- 断线恢复只能恢复同一已授权会话，不能延长原授权或恢复已过期令牌。
- SOVD、UDS/DoIP 和图形代理分别定义服务目录、权限、超时、审计和故障语义。
