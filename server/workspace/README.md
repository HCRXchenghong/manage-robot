# workspace/ 远程会话 Broker（云端）

架构文档阶段 2：远驾/运维要"上车"看现场——终端、GUI、诊断。
本服务是云端侧的会话编排器，与车端 `vehicle/workspace-agent/` 配对。

## 职责（生产形态）

1. **会话编排**：为每次远程接入建立授权会话（对接 `control-authority/`
   的终端令牌），分配车端目标与通道
2. **协议桥接**：浏览器（xterm.js / WebRTC）<-> 车端 PTY / SSH / GUI
3. **审计中枢**：按键级审计、命令录像、高危命令审批与双人复核
4. **断线恢复**：会话状态在车端保活（车端 agent 负责），云端负责
   重连路由，把用户接回原会话

## 当前状态（阶段 0）

云端 Broker 暂未实现：演示中远驾客户端（`client/core/terminal_client.py`）
凭令牌直连车端 `terminal_agent`（127.0.0.1:9600），授权链路已走通
（令牌仍由 `control-authority/` 签发、经 Gateway 送达车端）。

## 后续（生产化）

- 正式接入走加密隧道（QUIC / SSH），不暴露车端端口
- 多租户排队、并发会话限额、角色分权
- 审计与回放对接存储与合规流程
